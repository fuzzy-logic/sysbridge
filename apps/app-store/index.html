Apps live in the repo's store/<slug>/index.html. To add one, open a pull request with a single-file app carrying <title>, <meta name="description">, <meta name="app-icon"> and optionally app-version / app-author. It must be inline-only and talk to location.origin only; the catalogue test checks that. Installing needs the bridge token, which the bridge writes into this page's storage as it serves it.
